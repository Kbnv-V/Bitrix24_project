Обработчик для создания/обновления компаний в CRM.

Созданы для кастомного обмена с 1С.

1С создает компании в highload-блоке, далее каждый обработчик срабатывает на определенные события, либо на создание записи в highload-блоке, либо на изменение записи в highload-блоке.

Отдельный класс в файле correction_contact_data.php отвечает за нормализацию контактных данных, которые приходят из 1С.
