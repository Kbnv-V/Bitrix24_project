Тут представлены классы для обработки событий создания и изменения записей в Highload-блоке.

Данный код написан для интеграции с 1С:УП.
С 1С:УП настроена выгрузка контрагентов в Highload-блок. Далее обработчики событий делают свое дело.

company_appen - доабвляет компанию в CRM.
company_update - обновляет компанию в CRM.
correction_contact_data - исправляет контактные данные компании (телефоны, почтовые адреса).

Данное решение разработано из-за особенностей работы компании и ее требований.
Можно все это закрыть через штатный коннектор, но портал в компании развернут локально и недоступен из интернета (не проходили публикацию).
