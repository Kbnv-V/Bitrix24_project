Обработчик создан для того, чтобы ограничить публикацию сообщений в ленте новостей. 

Сделан для коробочного битрикс24. Срабатывает до публикации сообщения в ленте новостей. Сначала он получает ID сотрудника и его список групп. Далее идет проверка на содержание ID сотрудника в массиве с ID сотрудников, которым можно публиковать новость, если ID содержится в массиве, то сообщение публикуется, 
если нет, то переходим к следующей проверке. Далее проверка на группы пользователя. Если пользователь принадлежит к группе "Администраторы", то сообщение публикуется, если нет, то публикация отменяется и пользователю проходит уведомление о том, что у него нет прав на публикацию.
