Обработчик создан для уведомления о новых пользователях на портале. 

Так как на портале настроена синхронизация пользователей с Active Directory, то при появлении нового пользователя на портале у него нет отдела и он числится как экстранет-пользователь.

Обработчик срабатывает на событие создания нового пользователя на портале, отправляет уведомление ответственным сотрудникам в чат от лица системной учетной записи, а так же переносит нового пользователя в головной отдел структуры компании.
