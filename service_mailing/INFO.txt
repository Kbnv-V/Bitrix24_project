Файл upload_contact.php отвечает за изменение контакта после нажатия кнопки для отписки от рассылок.

В файле button_code.php лежит HTML код кнопки для отписки, который используется при рассылке.

Для подключения поля, которое поддерживает редактор html разметки подключал сервис tinymce. Папа с tinymce загружена частично, так как очень много файлов
