Обработчик события создания нового пользователя. 
StartAdaptation - Класс обработчика, который имеет 3 метода:
  - CreateElement: создает элемент смарт-процесса для старта адаптации
  - StartWorkflow: запускает бизнес-процесс по созданному элементу
  - WriteLog: метод для фиксации логов в файле

Обработчик запускает процесс адаптации для нового сотрудника, который только что появился на портале.
